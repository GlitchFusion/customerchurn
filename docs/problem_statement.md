# Option 2: Custom Logistic Regression for Churn Prediction

## Objective

Develop a logistic regression classifier from scratch using NumPy to predict customer churn in subscription-based platforms.

## Core Requirements

- EDA & feature engineering
- Implementation of:
  - Sigmoid function
  - Log-loss (cross-entropy)
  - Gradient descent
- Class imbalance handling
- Evaluation using:
  - Accuracy
  - Precision
  - Recall
  - F1 Score
  - ROC-AUC
- Benchmark with Scikit-learn
